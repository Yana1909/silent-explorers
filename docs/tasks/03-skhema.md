# Завдання 3. Помічник «Схема з підказками» (`createDiagramProject`)

Спершу прочитай [00-stack-i-pravyla.md](00-stack-i-pravyla.md): там стек, контракт модуля й правила здачі.

**Складність:** ★★★ (середня). **Орієнтовний час:** 8–12 годин.

## Що треба зробити

Написати **помічника** `window.createDiagramProject(...)`: показує одну картинку (фото або малюнок апарата) із світлими точками. Торкнувшись точки, глядач бачить назву й пояснення. Автор схеми не пише код: дає картинку та список точок.

Файл: `projects/_diagram.js`. Стилі: `css/styles.css`, класи `.diagram-…`.

## Стек

- **HTML + CSS**: позиціонування точок у відсотках (`left`/`top` у `%`) поверх картинки, `aspect-ratio`.
- **JavaScript**: показ/приховування підказки, розрахунок її положення, фокус і клавіатура.
- Без Canvas, без бібліотек.
- Мови: `window.pick`, `window.t`, `window.onLangChange`.

## Як викликається (API)

```js
window.createDiagramProject({
  id: "surveyor3",
  title: { en: "Inside Surveyor 3", uk: "Усередині Сервеєра-3" },
  author: "Ім'я або команда",
  image: { src: "assets/projects/surveyor3/scheme.jpg",
           alt: { en: "Diagram of the lander", uk: "Схема посадкового апарата" } },
  hotspots: [
    { x: 25, y: 40,                                   // відсотки від лівого й верхнього країв картинки
      label: { en: "Camera", uk: "Камера" },
      text:  { en: "Took thousands of photos.", uk: "Зробила тисячі знімків." } }
    // 1–8 точок
  ],
  note: undefined   // за замовчуванням: «Спрощена ілюстрація, без дотримання масштабу»
});
```

Обов'язкові: `id`, `image.src`, `hotspots` (мінімум одна точка з `x`, `y`, `label`). Якщо `x`/`y` поза 0–100, точку пропускаємо. Інакше помічник тихо виходить.

## Вимоги до поведінки

1. **Картинка повністю у сцені** (`object-fit: contain`), по центру. **Точки позиціюються відносно картинки, а не сцени**: якщо картинка не 16:10, навколо неї з'являються поля, і точки мусять лишатися на потрібних місцях. Для цього обгорніть картинку в блок із `position: relative` і `aspect-ratio`, що збігається з пропорціями файлу (беріть з `naturalWidth/naturalHeight` після завантаження), а точки ставте всередині нього.
2. **Точка** — кнопка з пульсацією (виглядом у стилі додатка), центр на `left: x%; top: y%` (`transform: translate(-50%, -50%)`). Область натискання ≥ 44×44 px, хоча видимий кружок може бути меншим.
3. **Натискання** показує підказку: назва (жирно) + текст. Підказка не виходить за межі сцени: перераховується положення (вище/нижче/ліворуч/праворуч від точки, з урахуванням місця).
4. **Закриття підказки:** повторне натискання на ту саму точку, натискання на іншу (перемикає), Esc, клік по порожньому місцю. **Esc закриває лише підказку, а не всю картку**: обробник Esc має зупиняти поширення події, поки підказка відкрита.
5. **Підказка-запрошення** «Торкнись точок» / «Tap the dots» видна, доки не натиснуто першу точку.
6. **Підпис «спрощено»** (`note`) видно завжди.
7. **Мова:** `t()` для інтерфейсу; зміна мови при відкритій картці оновлює тексти, відкрита підказка лишається відкритою.
8. **Доступність:** кожна точка — `<button>` з `aria-label` (назва), `aria-expanded`; навігація Tab; видимий фокус; підказка пов'язана з кнопкою (`aria-describedby` або `role="tooltip"`); `alt` у картинки.
9. **Помилка завантаження картинки:** повідомлення замість порожнього місця, без помилок у консолі.
10. **Рух:** при `prefers-reduced-motion` пульсація вимкнена.

## Технічна ідея

```js
// обгортка тієї ж пропорції, що й картинка
wrap.style.aspectRatio = img.naturalWidth + " / " + img.naturalHeight;

hotspots.forEach(function (h) {
  var b = document.createElement("button");
  b.className = "diagram-dot";
  b.style.left = h.x + "%";
  b.style.top = h.y + "%";
  b.setAttribute("aria-label", pick(h.label));
  b.addEventListener("click", function () { toggle(b, h); });
  wrap.appendChild(b);
});

// Esc всередині сцени закриває лише підказку
stage.addEventListener("keydown", function (e) {
  if (e.key === "Escape" && openTip) { closeTip(); e.stopPropagation(); }
});
```

Положення підказки: візьміть `getBoundingClientRect()` точки й сцени, поставте підказку над точкою, а якщо місця немає (менше висоти підказки до верху сцени), то під нею; по горизонталі обмежте так, щоб підказка не виходила за краї (`Math.max/Math.min`).

> Зверніть увагу: слухач Esc в `index.html` висить на `document`. Ваш слухач на елементі сцени спрацьовує **раніше**, лише якщо фокус усередині сцени. Після натискання на точку фокус на кнопці, тобто всередині. Перевірте, що це працює також після кліку мишею (деякі браузери не фокусують кнопки при кліку: тоді викличте `button.focus()` самі).

Текст підказок вставляйте через `textContent`, **не `innerHTML`**.

## Етапи роботи

1. **Каркас:** реєстрація, картинка в обгортці з правильною пропорцією, точки в потрібних місцях. (≈3 год)
2. **Підказка:** показ/приховування, перемикання між точками, розрахунок положення. (≈3 год)
3. **Esc, клавіатура, фокус, ARIA.** (≈2 год)
4. **Стилі, пульсація, підпис, мова, помилки.** (≈2 год)
5. **Перевірка, чек-лист, README.** (≈1–2 год)

## Критерії приймання

- [ ] Точки стоять на правильних місцях при картинках різних пропорцій (16:10, квадрат, вузька) і при розмірах 375 і 1440 px
- [ ] Підказка не виходить за межі сцени ні для яких точок (перевірте точки біля країв)
- [ ] Esc закриває підказку, але не картку; ще раз Esc закриває картку
- [ ] Усі точки доступні через Tab; відкриття Enter/пробілом; `aria-expanded` оновлюється
- [ ] Область натискання ≥ 44×44 px
- [ ] Зламаний шлях до картинки: повідомлення, консоль без помилок від модуля
- [ ] Підпис «спрощено» видно завжди
- [ ] Обидві мови; зміна мови при відкритій підказці її не закриває
- [ ] Після закриття картки нічого не лишилося (слухачі зняті)
- [ ] Загальний чек-лист із 00-stack-i-pravyla.md

## Підводні камені

- Якщо точки позиціонувати відносно сцени, а не картинки, вони «пливуть» при зміні розміру.
- Кнопки з розміром менше 44×44 px незручно натискати пальцем: робіть невидиму зону навколо видимого кружка (`padding` або `::before`).
- `aspect-ratio` не знає розмірів, доки картинка не завантажилась: ставте його в обробнику `load`.
- Підказка не повинна блокувати натискання сусідніх точок: закривається на клік по ним.

## Як перевірити

Створіть тимчасову схему з картинки, намальованої SVG-кодом (кілька фігур), і 4–6 точок. Не комітьте її. Допоміжний інструмент для координат: `demo/hotspot-picker.html` (якщо вже є); інакше способи з `docs/student/03-skhema.md`.
