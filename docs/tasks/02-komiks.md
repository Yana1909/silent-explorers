# Завдання 2. Помічник «Комікс» (`createComicProject`)

Спершу прочитай [00-stack-i-pravyla.md](00-stack-i-pravyla.md): там стек, контракт модуля й правила здачі.

**Складність:** ★★ (нижче середньої). **Орієнтовний час:** 6–10 годин. Хороше перше завдання.

## Що треба зробити

Написати **помічника** `window.createComicProject(...)`: показує в картці об'єкта серію кадрів, які гортаються свайпом, стрілками чи кнопками, з підписом під кожним кадром. Автор комікса не пише код: дає картинки й підписи.

Файл: `projects/_comic.js`. Стилі: `css/styles.css`, класи `.comic-…`.

## Стек

- **HTML + CSS** — основа: горизонтальна стрічка кадрів на **CSS scroll-snap**, свайп і прокрутка працюють самі, без JS.
- **JavaScript** — індикатор поточного кадру (`IntersectionObserver`), кнопки, клавіатура, попереднє завантаження сусідніх кадрів.
- Без Canvas, без бібліотек гортання.
- Мови: `window.pick`, `window.t`, `window.onLangChange`.

## Як викликається (API)

```js
window.createComicProject({
  id: "lrv17",
  title: { en: "The last drive", uk: "Остання поїздка" },
  author: "Ім'я або команда",
  frames: [
    { src: "assets/projects/lrv17/01.jpg",
      alt:     { en: "A buggy at the edge of a valley", uk: "Місяцехід на краю долини" },
      caption: { en: "The valley was quiet.", uk: "У долині було тихо." } }
    // 2–12 кадрів
  ],
  note: undefined   // за замовчуванням: «Малюнки учнів — вигадана розповідь за реальними фактами місії»
});
```

Обов'язкові: `id`, `frames` (мінімум 2 кадри, кожен із `src`). Інакше помічник тихо виходить. Текстові поля — рядок або `{ en, uk }`.

## Вимоги до поведінки

1. **Один кадр на екрані**, вписаний повністю (`object-fit: contain`) без обрізання; пропорція сцени 16:10 зберігається. Тло навколо кадру — з палітри застосунку.
2. **Гортання:** свайп/прокрутка (scroll-snap), кнопки «назад/далі», стрілки ← →; на першому кадрі кнопка «назад» вимкнена, на останньому «далі» вимкнена.
3. **Індикатор** «3 / 6» і крапки; клік по крапці веде до кадру. Поточний кадр визначається через `IntersectionObserver`, а не підрахунком прокрутки.
4. **Підпис** (`<figcaption>`) читається на будь-якому фоні, не закриває важливу частину малюнка.
5. **Завантаження.** Картинки `loading="lazy"`, а сусідні з поточним завантажуються наперед (`new Image().src = ...`). У пам'яті не тримаємо всі кадри одночасно, якщо це не потрібно.
6. **Помилка завантаження:** замість зламаної картинки показати повідомлення в рамці кадру (через `onerror`), без винятків у консолі.
7. **Підпис «вигадано»** (`note`) видно завжди.
8. **Мова:** інтерфейс через `t()`; зміна мови при відкритій картці оновлює підписи й `alt`, **не** скидаючи поточний кадр.
9. **Рух:** при `prefers-reduced-motion` плавна прокрутка вимкнена (`scroll-behavior: auto`).
10. **Доступність:** кожне зображення має `alt`; кнопки `aria-label`; перемикання кадрів клавіатурою; видимий фокус; область натискання кнопок ≥ 44×44 px.

## Технічна ідея

```html
<div class="comic">
  <ol class="comic-track">          <!-- display:flex; overflow-x:auto; scroll-snap-type:x mandatory -->
    <li class="comic-frame">        <!-- flex:0 0 100%; scroll-snap-align:center -->
      <figure><img ...><figcaption>...</figcaption></figure>
    </li>
  </ol>
  <div class="comic-controls">...</div>
</div>
```

```js
var io = new IntersectionObserver(function (entries) {
  entries.forEach(function (e) {
    if (e.isIntersecting && e.intersectionRatio > 0.6) setCurrent(frames.indexOf(e.target));
  });
}, { root: track, threshold: [0.6] });
frames.forEach(function (f) { io.observe(f); });

function goTo(i) { frames[i].scrollIntoView({ behavior: reduced ? "auto" : "smooth", inline: "center", block: "nearest" }); }
```

У `cleanup()` зніміть `io.disconnect()`, слухачі клавіатури й прибраний DOM.

Підписи й `alt` вставляйте через `textContent` / `setAttribute`, **не `innerHTML`**.

## Етапи роботи

1. **Каркас:** реєстрація, стрічка кадрів, scroll-snap, `cleanup`. (≈2 год)
2. **Кнопки, стрілки, індикатор, крапки.** (≈2 год)
3. **Завантаження й помилки:** `loading="lazy"`, попереднє завантаження сусідів, `onerror`. (≈1–2 год)
4. **Стилі й підписи.** (≈1–2 год)
5. **Мова й доступність.** (≈1–2 год)
6. **Перевірка, чек-лист, README.** (≈1 год)

## Критерії приймання

- [ ] Виклик із 2 та з 12 кадрами працює; з одним кадром або без `frames` — тихий вихід
- [ ] Свайп на телефоні (або емуляція дотику в DevTools), кнопки, стрілки ← → працюють; крайні кнопки вимкнені
- [ ] Індикатор і крапки завжди відповідають видимому кадру
- [ ] Зламаний шлях до картинки показує повідомлення, а не порожнечу, консоль без помилок від модуля
- [ ] Широка картинка й вузька вміщаються повністю
- [ ] Підпис «вигадано» видно завжди
- [ ] Обидві мови; зміна мови не скидає кадр
- [ ] Після закриття картки нічого не працює (`IntersectionObserver`, слухачі)
- [ ] Загальний чек-лист із 00-stack-i-pravyla.md

## Підводні камені

- `scroll-snap` і `IntersectionObserver` потребують, щоб `root` мав обмежену ширину й `overflow-x: auto`.
- Свайп по сцені не повинен «тягнути» сторінку: перевірте `overscroll-behavior` та `touch-action`.
- Картинки без заданої пропорції стрибають при завантаженні: задайте контейнеру кадру `aspect-ratio`.
- Довгі підписи на вузькому екрані: обмежте висоту й додайте прокрутку всередині підпису.

## Як перевірити

Зробіть тимчасовий вигаданий комікс із 4–6 кадрів із картинок-заглушок, які можна намалювати прямо в коді (SVG або кольорові прямокутники). Не комітьте його. Приклад вигаданої історії: `docs/student/01-komiks.md`.
