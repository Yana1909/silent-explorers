# Silent Explorers: стек технологій і спільні правила для розробників

Цей документ читають усі, хто виконує будь-яке з технічних завдань у цій папці (`01` … `04`). Він описує, **чим** ми пишемо код, **як** влаштований проєкт і **за якими правилами** приймається робота.

## 1. Про що проєкт

Silent Explorers — веб-застосунок для NASA Space Apps Challenge («Abandoned but not Forgotten»). На 3D-глобусі Місяця й Марса світяться точки: справжня техніка, яку залишили на поверхні. Торкнувшись точки, відкриваєш картку з розповіддю, фактами та **проєктом учня**: анімацією, грою, відео, коміксом, щоденником або схемою.

Ви пишете саме ці «проєкти»: **ядро (глобус, картки) вже готове**, а ваш код підключається до нього через простий контракт (розділ 4).

Живий сайт: https://yana1909.github.io/silent-explorers/ — репозиторій: https://github.com/Yana1909/silent-explorers

## 2. Стек

| Що | Технологія | Навіщо | Чого **не** використовуємо |
|---|---|---|---|
| Мова | **JavaScript** (звичайний, ES2015+) | працює в браузері без збірки | TypeScript, Babel, збирачі (Webpack, Vite) |
| Розмітка й стилі | **HTML5 + CSS3** із змінними (`var(--…)`) | кольори й шрифти беруться з `css/styles.css` | Tailwind, Bootstrap, Sass |
| Графіка | **Canvas 2D** (для ігор і анімацій), звичайний DOM + CSS (для тексту, комікса, схеми) | вистачає для наших задач і легко працює на телефонах | фреймворки ігор (Phaser, PixiJS), WebGL |
| Цикл анімації | `requestAnimationFrame` | рівна швидкість, зупиняється у фоновій вкладці | `setInterval` для анімацій |
| Ввід | **Pointer Events** (миша, дотик, стилус одним кодом) + клавіатура | однаково працює на ПК і телефоні | окремі `mouse*` і `touch*` обробники |
| Розмір | `ResizeObserver`, `devicePixelRatio` | чітка картинка на будь-якому екрані | фіксовані розміри в пікселях |
| Зберігання | `localStorage` у `try/catch` | дрібниці на кшталт «найкращий результат» | cookies, бази даних, сервери |
| Налаштування | `matchMedia("(prefers-reduced-motion: reduce)")` | повага до тих, кому заважає рух | |
| Мови | `Intl.PluralRules`, `Intl.Segmenter` | правильні закінчення й безпечний розбір тексту | бібліотеки перекладу |
| Хостинг | **GitHub Pages** (статичні файли) | безкоштовно | серверний код |
| Інструменти | VS Code, Git/GitHub, DevTools браузера, Squoosh (стиснення картинок), ffmpeg (відео) | | |

**Чому без фреймворків.** Сайт статичний, вантажиться миттєво, а контракт простий: один файл — один проєкт. Фреймворк тут лише ускладнив би підключення.

## 3. Структура проєкту

```
index.html              Головна сторінка: глобус, картки, дані про об'єкти
css/styles.css          Усі стилі (кольори й шрифти — змінні в :root)
js/i18n.js              Словник і функції t(), pick(), onLangChange()
projects/
  _template.js          Заготовка для canvas-проєкту
  _video.js             Помічник для відео (приклад, як робити помічників)
  eagle.js              Приклад анімації
  opportunity.js        Приклад гри
  <id>.js               Проєкт для конкретного об'єкта
assets/img/             Фото NASA
assets/video/           Відео
assets/projects/<id>/   Матеріали проєкту (картинки, файли)
docs/                   Документація
```

Об'єкти (`id`): `eagle`, `lunokhod2`, `lrv17`, `surveyor3`, `opportunity`, `spirit`, `viking1`, `insight`, `perseverance-debris`.

Файли, що починаються з підкреслення (`_video.js`), — це **помічники та шаблони**, а не проєкти.

## 4. Контракт проєкту

Кожен проєкт реєструє себе в глобальному об'єкті:

```js
(function () {
  window.STUDENT_PROJECTS = window.STUDENT_PROJECTS || {};
  window.STUDENT_PROJECTS["lrv17"] = {
    title: "Назва",           // рядок або { en: "...", uk: "..." }
    author: "Ім'я або команда",
    type: "game",             // "animation" | "game" | "video" | "comic" | "diary" | "diagram"
    init: function (container, item) {
      // container — порожній <div> приблизно 16:10, вже має розмір
      // item — дані об'єкта (назва, факти…) — можна читати, не змінювати
      // ... будуємо інтерфейс усередині container, запускаємо цикл ...
      return function cleanup() {
        // зупини таймери й requestAnimationFrame, зніми всі слухачі,
        // звільни ресурси, прибери зі сторінки те, що створив
      };
    }
  };
})();
```

**Найважливіше правило — `cleanup()`.** Його викликають, коли картку закривають або відкривають іншу. Після нього **нічого не повинно працювати**: ні таймер, ні анімація, ні звук, ні слухачі на `window` чи `document`. Перевіряйте це самі (розділ 8).

Якщо проєкт підключається до `index.html`, у кінці списку скриптів додається один рядок: `<script src="projects/<id>.js"></script>`. Помічники (`_diary.js` тощо) підключаються **раніше** за проєкти, які їх викликають.

## 5. Дві мови

У застосунку є перемикач EN | УК. Для вас важливо:

- `window.t("ключ", {параметри})` повертає рядок інтерфейсу поточною мовою;
- `window.pick(значення)` приймає рядок **або** `{ en, uk }` і повертає текст поточної мови (якщо мови немає — англійську);
- `window.onLangChange(fn)` викликає вашу функцію, коли мову змінили. **Мова може змінитися, поки картка відкрита**: оновіть тексти, але **не перезапускайте** гру чи відео.

Усі ваші тексти інтерфейсу (кнопки, повідомлення, підписи) мають бути обома мовами. Тексти проєкту (підписи, записи) — теж, якщо автор дав обидві мови; якщо дав одну, її показують у обох режимах.

> Перемикач мови додається окремою роботою. Поки його немає, користуйтеся `window.pick ? window.pick(x) : x`, а коли він з'явиться, нічого не доведеться переробляти.

## 6. Правила

1. **Достовірність.** Факти (дати, цифри, назви) беремо з картки об'єкта або з NASA й інших надійних джерел; посилання записуємо. Вигадане позначаємо. Кожен формат має обов'язковий підпис «придумано» / «спрощено», його не прибирають.
2. **Без зовнішніх бібліотек і запитів.** Весь код і всі файли лежать у репозиторії. Жодних трекерів, аналітики, шрифтів чи скриптів із сторонніх сайтів (окрім тих, що вже підключені в `index.html`).
3. **Безпека.** Текст учнів (підписи, записи) вставляємо **тільки через `textContent`**, а не через `innerHTML`. Інакше хтось зможе вставити в підпис код.
4. **Доступність.** Усе керується з клавіатури (Tab, Enter, пробіл, стрілки, Esc), є видимий фокус; кнопки мають `aria-label`; у картинок є `alt`; область натискання не менша за 44×44 px; контраст тексту достатній; рух вимикається при `prefers-reduced-motion`.
5. **Продуктивність.** Модуль без картинок — до 40 КБ; матеріали проєкту — до 8 МБ разом; нічого важкого не вантажиться, доки картку не відкрито; у циклі анімації не створюємо нових об'єктів без потреби.
6. **Звук.** Ніколи не запускається сам: тільки після натискання користувача, і завжди є кнопка вимкнення.
7. **Не чіпаємо чуже.** Не змінюємо дані об'єктів (`DATA` в `index.html`), чужі проєкти та `assets/img/`.
8. **Стиль коду.** Простий і читабельний; назви змінних говорять самі за себе. Коментар — тільки там, де інакше незрозуміло **чому** так зроблено. Кольори й шрифти — змінні з `css/styles.css`, а не «зашиті» значення.

## 7. Як запустити локально

Відкривати `index.html` подвійним кліком **не можна**: скрипти не працюватимуть. Потрібен локальний сервер:

```bash
python -m http.server 8000 --protocol HTTP/1.1
```

(виконувати в папці проєкту, потім відкрити `http://localhost:8000`). Прапорець `--protocol HTTP/1.1` потрібен: без нього сервер іноді обриває завантаження великих файлів, і проєкти «не підключаються». Альтернатива — розширення Live Server у VS Code.

Браузер кешує сторінку: після змін відкривайте з новим параметром (`?v=2`) або натискайте Ctrl+F5.

## 8. Перевірка перед здачею

Заповніть чек-лист у своєму PR.

- [ ] Працює на ширині **375 px** (телефон) і **1440 px** (комп'ютер), немає горизонтальної прокрутки
- [ ] Консоль DevTools без помилок і попереджень від вашого коду
- [ ] **Закрила картку — все зупинилося**: у DevTools → Performance або через `console.log` у `cleanup()` перевірте, що цикл не працює; відкрила іншу картку — нічого зайвого не лишилося
- [ ] Відкрила й закрила картку 10 разів поспіль: нічого не «нашаровується», швидкість не падає
- [ ] Клавіатура: усе доступне через Tab, є видимий фокус, Esc закриває картку (а підказку — якщо вона відкрита)
- [ ] Мова: обидві мови, зміна мови при відкритій картці нічого не ламає
- [ ] Текст не обрізається і не вилазить за межі картки в обох мовах (українська довша на 15–25%)
- [ ] `prefers-reduced-motion`: у DevTools → Rendering увімкніть «Emulate prefers-reduced-motion», рух зменшився
- [ ] Факти перевірені, джерела записані
- [ ] Обов'язковий підпис («придумано»/«спрощено») показується
- [ ] Не змінено нічого поза вашими файлами (окрім одного рядка `<script>` і, за потреби, підпису типу в `index.html`)

## 9. Git і здача

1. Кожен працює у **своїй гілці**: `project/<id>-<формат>` або `helper/<назва>`, наприклад `helper/diary`, `project/lrv17-game`.
2. Комітьте часто, повідомлення коротко й по суті («Add typewriter effect», а не «fix»).
3. Готове — **Pull Request** у `main`. Ментор перевіряє за чек-листом і дає зауваження.
4. Після злиття GitHub Pages оновиться за 1–2 хвилини.
5. У `main` напряму не пушимо.
