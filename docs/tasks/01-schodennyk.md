# Завдання 1. Помічник «Щоденник / лист апарата» (`createDiaryProject`)

Спершу прочитай [00-stack-i-pravyla.md](00-stack-i-pravyla.md): там стек, контракт модуля й правила здачі.

**Складність:** ★★★ (середня). **Орієнтовний час:** 8–12 годин.

## Що треба зробити

Написати **помічник**: функцію `window.createDiaryProject(...)`, яка за налаштуваннями показує в картці об'єкта текст від імені апарата. Записи «друкуються» на екрані, між ними можна гортати. Автор проєкту потім **не пише код**: просто викликає помічника зі своїм текстом.

Файл: `projects/_diary.js`. Стилі: в `css/styles.css`, класи з префіксом `.diary-`.

## Стек

- Чистий **JavaScript** + **DOM** + **CSS** (без Canvas: тут це текст).
- `requestAnimationFrame` для ефекту друку.
- `Intl.Segmenter` (розбиття тексту на символи; запасний варіант `Array.from`).
- `matchMedia("(prefers-reduced-motion: reduce)")`.
- Мови: `window.pick`, `window.onLangChange`.

## Як викликається (API)

```js
window.createDiaryProject({
  id: "lunokhod2",
  title: { en: "Diary of Lunokhod 2", uk: "Щоденник Лунохода-2" },
  author: "Команда Navis",
  style: "log",                                  // "log" (бортовий журнал) або "letter" (лист)
  signature: { en: "Lunokhod 2", uk: "Лунохід-2" },
  entries: [
    { date: { en: "January 1973", uk: "січень 1973" },
      text:  { en: "I have landed...", uk: "Я приземлився..." } }
    // 1–10 записів
  ],
  note: undefined   // за замовчуванням — обов'язковий підпис «вигадано» (його можна лише замінити)
});
```

Усі текстові поля — рядок **або** `{ en, uk }`. Обов'язкові: `id`, `entries` (хоча б один запис із `text`). Якщо їх немає, помічник тихо виходить (нічого не ламає й не пише в консоль).

## Вимоги до поведінки

1. **Один запис на екрані.** Дата зверху, текст нижче, підпис апарата внизу останнього запису.
2. **Ефект друку.** Символи з'являються по черзі: у середньому 25–40 мс на символ, після `. ! ? …` пауза довша, після `, ;` коротша.
3. **Кнопка «Показати все»** (`Show all` / `Показати все`): одразу відкриває весь запис. Після друку кнопка зникає.
4. **Гортання:** кнопки «назад/далі», стрілки ← → на клавіатурі, свайп (за бажанням). Індикатор «2 / 5». При переході наступний запис починає друкуватися.
5. **Вигляд.** `letter`: ніби аркуш паперу, рукописний вигляд, підпис унизу. `log`: моноширинний шрифт, дата у виділеній мітці, рядок «режим журналу». Колір і шрифти — змінні з `css/styles.css`, шрифт з кирилицею.
6. **Підпис** (`note`): у стандартному варіанті «Imagined diary — written from real mission facts» / «Вигаданий щоденник за реальними фактами місії». Видно завжди під текстом.
7. **Мова.** Інтерфейс (кнопки, індикатор) — через `t()`. Зміна мови при відкритій картці: поточний запис показується **повністю** відразу, ефект не перезапускається.
8. **Рух.** Якщо `prefers-reduced-motion`, ефекту друку немає: текст з'являється одразу.
9. **Доступність.** Скрін-рідер читає **весь текст запису одразу** (а не по літері): тому весь текст лежить у DOM, а «друк» лише відкриває його візуально. Область у `aria-live` **не** робимо (інакше читач зачитуватиме кожну літеру). Кнопки мають підписи.
10. **Довгий текст.** Запис до 500 символів умістився на екрані 375 px або прокручується всередині сцени.

## Технічна ідея (щоб не було «стрибків» рядків)

Якщо просто дописувати літери в елемент, слово, яке не вмістилося в кінці рядка, у мить друку **перестрибує** на новий рядок, і текст смикається. Зробіть інакше:

1. Одразу виведіть **весь** текст у DOM.
2. Кожне слово загорніть у `<span class="diary-word">` із `white-space: nowrap`, кожен символ — у `<span class="diary-ch">` з `opacity: 0`.
3. Заздалегідь порахуйте масив часів `times[i]`: накопичена затримка до появи `i`-го символу (з паузами після розділових знаків).
4. У `requestAnimationFrame` рахуйте `elapsed = now - start` і відкривайте всі символи, чий час настав.

```js
function graphemes(text) {
  if (window.Intl && Intl.Segmenter) {
    var seg = new Intl.Segmenter(undefined, { granularity: "grapheme" });
    return Array.from(seg.segment(text), function (s) { return s.segment; });
  }
  return Array.from(text);
}

function scheduleTimes(chars) {
  var t = 0, times = [];
  chars.forEach(function (c) {
    times.push(t);
    t += 30;                                   // базова швидкість, мс
    if (".!?…".indexOf(c) !== -1) t += 250;
    else if (",;:".indexOf(c) !== -1) t += 110;
  });
  return times;
}

function play(spans, times) {
  var start = performance.now(), shown = 0, raf;
  function frame(now) {
    var elapsed = now - start;
    while (shown < spans.length && times[shown] <= elapsed) {
      spans[shown++].style.opacity = "1";
    }
    if (shown < spans.length) raf = requestAnimationFrame(frame);
  }
  raf = requestAnimationFrame(frame);
  return function stop() { cancelAnimationFrame(raf); };
}
```

Текст записів вставляйте через `textContent` кожного `span`, **не `innerHTML`**.

## Етапи роботи

1. **Каркас.** `createDiaryProject` реєструє запис у `STUDENT_PROJECTS`; `init` будує порожню розмітку, `cleanup` її прибирає. Один запис без ефектів. (≈2 год)
2. **Друк.** Розбиття на символи, `times`, відображення, кнопка «Показати все». (≈3 год)
3. **Гортання й індикатор.** Кнопки, стрілки, початок друку при переході. (≈2 год)
4. **Стилі `letter` та `log`.** (≈2 год)
5. **Мова й доступність.** `pick`, `t`, `onLangChange`, `prefers-reduced-motion`, фокус. (≈2 год)
6. **Перевірка й чек-лист**, README. (≈1–2 год)

## Критерії приймання

- [ ] Виклик із 1 та з 10 записами працює; без `entries` нічого не ламається й нічого не пише в консоль
- [ ] Текст «друкується» без стрибків рядків (перевірте на ширині 375 px)
- [ ] «Показати все», гортання кнопками, стрілками клавіатури; індикатор правильний
- [ ] Закрила картку посеред друку: у `cleanup()` зупинено `requestAnimationFrame`, нічого не продовжує працювати
- [ ] Скрін-рідер (або DevTools → Accessibility) бачить повний текст запису
- [ ] Українські літери і ї є ґ відображаються нормально й не розбиваються при друку
- [ ] Підпис «вигадано» видно завжди
- [ ] Обидві мови; зміна мови при відкритій картці не перезапускає друк
- [ ] `prefers-reduced-motion`: без друку
- [ ] Загальний чек-лист із 00-stack-i-pravyla.md

## Підводні камені

- Розбиття на `char` через `text.split("")` ламає складні символи (нехай це буде `Intl.Segmenter`).
- Якщо ховати текст через `display: none`, розмітка стрибатиме: треба `opacity: 0`.
- Забули `cancelAnimationFrame` у `cleanup()` — друк продовжується після закриття й «живе» у фоні.
- `innerHTML` з чужим текстом — дірка в безпеці.
