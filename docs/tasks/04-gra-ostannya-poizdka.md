# Завдання 4. Гра «Остання поїздка» (місяцехід Apollo 17)

Спершу прочитай [00-stack-i-pravyla.md](00-stack-i-pravyla.md): там стек, контракт модуля й правила здачі. Дивись також готовий приклад гри: `projects/opportunity.js`.

**Складність:** ★★★★ (найскладніше з усіх). **Орієнтовний час:** 20–30 годин. Рекомендована команда: 2–3 людини (рушій і керування / світ і перешкоди / інтерфейс і стани).

## Що треба зробити

Написати міні-гру для об'єкта **`lrv17`** (Lunar Roving Vehicle, Apollo 17). Це **проєкт, а не помічник**: файл `projects/lrv17.js`, який реєструє себе в `STUDENT_PROJECTS["lrv17"]` з `type: "game"`.

## Тема й історія (лише перевірені факти)

З картки об'єкта: у грудні 1972 року Джин Сернан і Джек Шміт їздили на цьому місяцеході по долині Таурус-Літтров три дні, проїхали 35,9 км, возили інструменти, гравіметр і зразки породи (екіпаж привіз додому 110,5 кг зразків). Наприкінці вони залишили його приблизно за 160 м від посадкового модуля, **спрямувавши його телекамеру на модуль**, щоб Центр управління міг бачити зліт. З того часу до нього ніхто не торкався.

Гра ставить дитину на місце астронавтів: **зібрати зразки й залишити місяцехід так, щоб його камера дивилася на посадковий модуль перед стартом**.

> Гра спрощена, це не симуляція. Під грою завжди видно підпис «Simplified game — not a simulation» / «Спрощена гра, а не симуляція». Справжні числа (35,9 км, 110,5 кг) показуються на екрані результату окремо від ігрових.

## Стек

- **JavaScript** + **Canvas 2D** (вид зверху, камера слідує за машиною).
- `requestAnimationFrame` із **обмеженням кроку часу** (`dt ≤ 0.05 с`).
- **Pointer Events** для сенсорного керування, `keydown/keyup` для клавіатури.
- **Генерація світу з фіксованим насінням** (простий генератор `mulberry32`), щоб рівень був однаковим при кожному запуску й його можна було налаштовувати.
- Малюємо **примітивами Canvas** (прямокутники, кола, `Path2D`): без зображень, без бібліотек.
- Опційно: `localStorage` для найкращого результату (`try/catch`).
- Мови: `window.t`, `window.pick`, `window.onLangChange`.

## Ігровий процес

**Сесія 90–120 секунд.** Вид зверху. Світ завбільшки 2400 × 1600 (умовні одиниці), видимо вікно ≈ 800 × 500, камера плавно слідує за машиною.

1. **Старт.** Екран «Як грати» зі схемою керування й кнопкою «Почати». **Гра не стартує сама.**
2. **Їзда.** Прискорення, гальмо, поворот. Місяцехід має інерцію: різко не зупиняється, у поворотах трохи «ковзає».
3. **Станції зі зразками.** П'ять позначених місць (прапорці). Заїхав у коло й утримуєшся ≈ 1,5 с: зразок зібрано, лічильник росте. Кожен зразок ≈ 22 кг, разом 5 × 22,1 = 110,5 кг (шкала «Зразки: 44 / 110,5 кг»).
4. **Перешкоди.** Валуни (відштовхують і сповільнюють) і кратери (всередині швидкість обмежена). Нічого не вбиває: перешкоди лише забирають час.
5. **Час.** Таймер із 120 с: показує, що в астронавтів не було безмежного часу.
6. **Фінал.** Коли зібрано **щонайменше три** зразки, з'являється стрілка до посадкового майданчика. Заїдь у зону, розверни місяцехід до посадкового модуля, зупинись і натисни «Увімкнути камеру». Камера дивиться на модуль, показується короткий кадр «зліт здалеку» (умовний: схематична ракета й слід). Підпис: «Ніхто не торкався його відтоді».
7. **Результат.** Екран з підсумком гри (зібрано N кг, час) і **справжніми фактами**: «У справжній місії: 35,9 км за три дні, 110,5 кг зразків за всю місію». Кнопка «Грати знову».

Втрата часу без зібраних зразків: «Час вийшов» — теж екран з фактами й кнопкою «Спробувати ще раз». Програти «до сліз» не можна: гра дружня.

## Структура коду

```js
(function () {
  window.STUDENT_PROJECTS = window.STUDENT_PROJECTS || {};
  window.STUDENT_PROJECTS["lrv17"] = {
    title: { en: "The Last Drive", uk: "Остання поїздка" },
    author: "Команда Navis",
    type: "game",
    init: function (container) {
      // 1. DOM: обгортка, canvas, HUD, кнопки, регіон повідомлень
      // 2. стан гри: { phase: "intro"|"playing"|"paused"|"ending"|"result", ... }
      // 3. світ із насінням, машина, камера
      // 4. ввід: клавіатура + Pointer Events
      // 5. цикл update(dt) / render()
      return function cleanup() { /* усе зупинити й прибрати */ };
    }
  };
})();
```

Цикл (з паузою у фоновій вкладці):

```js
var raf = 0, last = performance.now(), running = true;

function frame(now) {
  if (!running) return;
  var dt = Math.min((now - last) / 1000, 0.05);   // крок не більше 50 мс
  last = now;
  if (state.phase === "playing") update(dt);
  render();
  raf = requestAnimationFrame(frame);
}
function onVisibility() {
  if (document.hidden && state.phase === "playing") state.phase = "paused";
}
document.addEventListener("visibilitychange", onVisibility);
raf = requestAnimationFrame(frame);

return function cleanup() {
  running = false;
  cancelAnimationFrame(raf);
  document.removeEventListener("visibilitychange", onVisibility);
  // зняти слухачі клавіатури, Pointer Events, ResizeObserver; прибрати DOM
};
```

Простий кінематичний рух машини:

```js
car.angle += steer * TURN_RATE * (car.speed / MAX_SPEED) * dt;
car.speed += (throttle * ACCEL - DRAG * car.speed) * dt;
car.x += Math.cos(car.angle) * car.speed * dt;
car.y += Math.sin(car.angle) * car.speed * dt;
```

Генератор насіння (щоб світ був завжди однаковий):

```js
function mulberry32(a) {
  return function () {
    a |= 0; a = (a + 0x6D2B79F5) | 0;
    var t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```

Зіткнення: кола проти кіл (`dx*dx + dy*dy < r*r`), перебором. Об'єктів менше ста, оптимізація не потрібна. Малюйте тільки те, що потрапляє у вікно камери.

## Вимоги

1. **Керування:**
   - клавіатура: стрілки або WASD (газ / гальмо / повороти), `Space` — «увімкнути камеру» у фіналі, `P` — пауза;
   - дотик: екранні кнопки «ліворуч», «праворуч», «газ», «гальмо» на **Pointer Events** із `setPointerCapture`. Кілька пальців одночасно (газ і поворот) працюють.
2. **Стрілки й пробіл не повинні прокручувати сторінку**, коли гра в фокусі (`preventDefault` лише для цих клавіш і лише в грі). **Esc не перехоплювати**: він закриває картку.
3. **Розмір.** Canvas масштабується під контейнер (`ResizeObserver`, `devicePixelRatio`), пропорція 16:10; логічна сцена фіксована (наприклад, 800 × 500), щоб гра не залежала від розміру екрана.
4. **Стани.** «Як грати» → гра → пауза → фінал → результат → «Грати знову». Пауза автоматична, коли вкладка прихована.
5. **Мови.** Усі написи (HUD, кнопки, екрани, підпис) через `t()` / `pick()`. Зміна мови при відкритій картці не перезапускає гру: перемальовується інтерфейс.
6. **Доступність.** Невеликий `aria-live="polite"` регіон повідомляє про ключові події («Зразок зібрано», «Час вийшов», «Камеру націлено»): рідко, не щокадру. Кнопки справжні `<button>` з підписами. Контейнеру гри `tabindex="0"`, видимий фокус. Колір не єдиний носій інформації (станції мають ще й форму/іконку).
7. **Рух.** При `prefers-reduced-motion`: без трясіння екрана й сильних ефектів пилу, фінальний кадр «зліт» показується статично.
8. **Звук.** За замовчуванням його **немає**. Якщо робите (за бажанням), то лише після натискання користувача, через Web Audio, із кнопкою вимкнення.
9. **Продуктивність.** 60 кадрів/с на середньому телефоні. Пил — **пул** повторно використовуваних частинок (до 60), без створення нових об'єктів у кожному кадрі.
10. **Підпис «спрощено»** і джерела фактів: `docs/` або коментар у файлі.

## Критерії приймання

- [ ] Гра запускається тільки після «Почати», проходиться від початку до кінця за 90–120 с
- [ ] Керування клавіатурою **і дотиком** (перевірте в емуляції телефона в DevTools)
- [ ] Збір зразків, лічильник кг, таймер, фінал «увімкнути камеру» та екран з реальними фактами працюють
- [ ] Дві мови, зміна мови не скидає гру
- [ ] Закрила картку посеред гри: цикл зупинено, слухачі зняті, нічого не працює у фоні (перевірте `console.log` у `cleanup()` і вкладку Performance)
- [ ] Вкладку приховано: гра на паузі
- [ ] Стрілки й пробіл не прокручують сторінку; Esc закриває картку
- [ ] 60 кадрів/с у DevTools → Performance (емуляція CPU ×4 теж не рветься)
- [ ] 375 і 1440 px, нічого не вилазить, кнопки ≥ 44×44 px
- [ ] Підпис «спрощено» видно, факти на екрані результату відповідають картці об'єкта
- [ ] Загальний чек-лист із 00-stack-i-pravyla.md

## Підводні камені

- Цикл на `setInterval` дає ривки, а не на `requestAnimationFrame` із `dt`.
- Без обмеження `dt` після повернення на вкладку машина «телепортується» крізь перешкоди.
- Забули `preventDefault` для стрілок — сторінка гойдається під час гри; зробили його завжди — зламали стрілки в усій сторінці. Тільки в грі.
- Слухачі на `window` / `document` без `removeEventListener` у `cleanup()`.
- Розмиття картинки на ретина-екранах без масштабування canvas на `devicePixelRatio`.
- Складні фізичні ефекти: тут вистачає простої кінематики.
