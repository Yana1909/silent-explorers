# ТЗ для агента-техника: три новых формата проектов (комикс, дневник, схема)

## 1. Контекст

Silent Explorers — статическое веб-приложение без сборки (HTML/CSS/JS, three.js r0.128 с CDN), хостится на GitHub Pages: https://yana1909.github.io/silent-explorers/. На карте 9 объектов; у каждого карточка со «сценой» `#projectStage` (около 16:10), куда подключается проект ученика через реестр `window.STUDENT_PROJECTS[id] = { title, author, type, init(container, item) → cleanup }`.

Уже есть три типа: `animation`, `game` (оба на canvas) и `video` (помощник `window.createVideoProject` в `projects/_video.js`). Ученики будут приносить проекты разных форматов, и большинство не умеет программировать. Поэтому код форматов делаем заранее, в виде помощников, а ученик заполняет только содержание.

Перед работой прочитать: `README.md`, `docs/DESIGN_NOTES.md`, `docs/TECH_BRIEF.md`, `index.html` целиком, `css/styles.css`, `projects/_video.js`, `projects/perseverance-debris.js`, `projects/_template.js`. Новые помощники делать по образцу `_video.js`: тот же стиль, та же схема «короткий файл проекта вызывает помощника».

Папка проекта: `C:\Users\3sidj\OneDrive\Рабочий стол\Посилання\silent-explorers`.

## 2. Задача

Сделать три помощника и всё необходимое вокруг них, чтобы потом проект ученика подключался без правок логики:

| Формат | Помощник | `type` | Что даёт ученик |
|---|---|---|---|
| Комикс | `createComicProject` | `comic` | 4–8 картинок и подписи |
| Дневник / письмо аппарата | `createDiaryProject` | `diary` | записи с датами и текстом |
| Схема с подсказками | `createDiagramProject` | `diagram` | одну картинку и список точек с текстом |

Содержимое реальных объектов (девять маркеров) в этой задаче **не создавать и не подключать**: у объектов должно остаться то, что есть сейчас. Всё демонстрационное содержание живёт отдельно (см. 4.6).

## 3. Общие требования ко всем помощникам

- Вызов: `window.createXxxProject({ id, title, author, ...поля формата })`. Регистрирует обычную запись в `STUDENT_PROJECTS` с нужным `type`. Не вызывать повторно и не падать, если `id` или обязательные поля не заданы (тихо выйти, как в `_video.js`).
- Файл проекта ученика — один короткий файл `projects/<id>.js` с одним вызовом помощника; материалы лежат в `assets/projects/<id>/`.
- **Контракт `init/cleanup`.** `cleanup()` обязан остановить таймеры и анимации, снять слушатели, освободить ресурсы. После закрытия карточки или перехода к другой ничего не должно продолжать работать.
- **Достоверность.** У каждого формата есть обязательная подпись `note` с значением по умолчанию, и убрать её через настройки нельзя (можно только заменить текстом):
  - комикс: `Student artwork — an imagined retelling based on real mission facts`
  - дневник: `Imagined diary — written from real mission facts`
  - схема: `Simplified illustration — not to scale`
- **Размер и скорость.** Ничего тяжёлого не загружается, пока карточка не открыта. Картинки грузятся лениво. Рекомендуемые лимиты записать в документацию, а в коде при превышении ничего не блокировать.
- **Доступность.** Всё управляется с клавиатуры (стрелки, Tab, Enter), у картинок есть `alt` (поле в настройках, обязательное в шаблонах), видимый фокус. Учитывать `prefers-reduced-motion`: без печатающего эффекта, без автоповорота, без анимации листания.
- **Тач.** Свайп для комикса, касание для точек схемы. Области нажатия не меньше 44×44 px.
- **Ошибки.** Если картинка или файл не загрузились, показать понятное сообщение в сцене, не писать исключений в консоль из модуля.
- **Стиль.** Использовать переменные и приёмы из `css/styles.css`, классы с префиксами `.comic-`, `.diary-`, `.diagram-`. Не менять внешний вид существующих элементов.
- Без сборки, фреймворков и новых библиотек.
- **Два языка (EN / УК).** К моменту выполнения этого ТЗ в проекте уже есть переключатель языка (см. `docs/TECH_BRIEF_I18N.md`, `window.t()`, `window.pick()`, `window.onLangChange`). Все строки интерфейса помощников (кнопки, сообщения об ошибках, подсказки «Нажми на точки», индикаторы «3 / 6», `aria-label`) брать из словаря, с английским и украинским вариантами. Поля `title`, `author`, `caption`, `alt`, `text`, `label`, `note`, `signature` принимают строку либо `{ en, uk }` (через `pick`); если дали только строку, она показывается в обоих языках. Язык можно сменить при открытой карточке: помощник обновляет тексты без перезапуска сцены. Обязательные подписи `note` по умолчанию на украинском: комикс «Малюнки учнів — вигадана розповідь за реальними фактами місії», дневник «Вигаданий щоденник за реальними фактами місії», схема «Спрощена ілюстрація, без дотримання масштабу».
- В интерфейсе новые типы получают метки в карточке и в коллекции, как у `video`: `COMIC`, `DIARY`, `DIAGRAM`. Маркер на глобусе и карточка коллекции для объектов с проектом любого типа выглядят одинаково (как сейчас у видео).

## 4. Требования по форматам

### 4.1. Комикс — `createComicProject`
Поля: `frames: [{ src, alt, caption }]` (от 2 до 12 кадров), `note`.
- Один кадр на экране, соотношение сцены сохранять (кадр вписывается целиком, `object-fit: contain`).
- Переход: кнопки «назад/вперёд», стрелки клавиатуры, свайп; индикатор «3 / 6» и точки.
- Подпись кадра под картинкой или поверх, читаемая на любом фоне.
- Следующий кадр подгружается заранее (предзагрузка только соседних кадров).

### 4.2. Дневник / письмо — `createDiaryProject`
Поля: `entries: [{ date, text }]` (1–10 записей), `signature` (например, имя аппарата), `note`, необязательно `style: "letter" | "log"`.
- Оформление «бумажного письма» или «бортового журнала» в стиле приложения; шрифт с кириллицей.
- Текст «печатается» по буквам; кнопка «показать сразу»; при `prefers-reduced-motion` печатающего эффекта нет.
- Записи листаются, как в комиксе; запись целиком читается без прокрутки на ширине 375 px либо прокручивается внутри сцены.
- Весь текст доступен скрин-ридеру сразу целиком (не по буквам).

### 4.3. Схема с подсказками — `createDiagramProject`
Поля: `image: { src, alt }`, `hotspots: [{ x, y, label, text }]` (x и y в процентах от картинки, 0–100), `note`.
- Картинка целиком в сцене, поверх неё кнопки-точки; нажатие показывает подсказку (название и текст) рядом с точкой или под схемой, чтобы не выходила за границы на узком экране.
- Подсказка закрывается повторным нажатием, Esc или нажатием на другую точку. **Esc в этот момент закрывает только подсказку, а не всю карточку** (проверить, что обработчик Esc карточки не конфликтует).
- Все точки доступны через Tab, у каждой `aria-label`. Подсказка «Нажми на точки» исчезает после первого нажатия.
- Позиции точек должны оставаться на нужных местах при любом размере сцены.

### 4.4. Интеграция
- Метки типов, описанные в разделе 3; проверить подпись «Student project…» в карточке и работу счётчика «Found N of 9».
- В `index.html` подключать помощники одним блоком `<script>` перед файлами проектов; порядок загрузки прописать комментарием. Файлы с подчёркиванием работают на GitHub Pages благодаря `.nojekyll` — не удалять.
- Тип проекта не должен влиять на `stopActiveProject()`: любой тип закрывается и очищается одинаково.

На страницу ведёт ссылка только из `README.md`; в `<head>` поставить `<meta name="robots" content="noindex">`. На карте и в карточках реальных объектов демо-данные не используются никогда.
- Для демонстрационных картинок использовать только материалы без вопросов к лицензии: нарисовать SVG-кодом самому.
- Для каждого формата шаблон проекта `projects/_template-<format>.js` с комментариями и заполненными подсказками (что писать в каждом поле, какие лимиты).

## 7. Проверка
Запуск: `python -m http.server 4195 --protocol HTTP/1.1 --directory "<папка проекта>"` (`python3` на этой машине не работает; без `--protocol HTTP/1.1` сервер обрывает крупные файлы; перемотка видео на нём не работает — это его ограничение). После правок обновлять страницу без кеша, в браузере проверять состояние через `javascript_tool`.

На `demo/index.html` для каждого формата:
- комикс: листание кнопками, стрелками и свайпом; индикатор; ошибка при битой картинке;
- дневник: печать, кнопка «показать сразу», режим уменьшенного движения (эмулировать `prefers-reduced-motion`);
- схема: точки на нужных местах на 375 и 1440 px, подсказка не выходит за экран, Esc закрывает подсказку, но не карточку;
- ширина 375 и 1440 px, нет горизонтальной прокрутки, консоль без ошибок, клавиатурное управление.

На основном сайте (`index.html`): всё как раньше — Eagle, Opportunity, видео Perseverance и карточка без проекта (Spirit); новые типы реально не подключены к объектам; счётчик «of 9» без изменений.
